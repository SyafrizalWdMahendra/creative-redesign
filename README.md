--Tech Stack--
Framework : Laravel 12
PHP Version : 8.2.12
Database : MySQL

Cara Instalasi

1. Buat database dengan nama "creative_redesign"
2. masuk ke folder creative-redesign, kemudian jalankan perintah "php artisan serve"
3. jika ingin masuk ke dashboard panel admin, tekan button 'login'

Credential Akun:
email : care@creativemedia.id
password : creative_M.id

4. selesai

Fitur yang tersedia:
menu beranda, bidang studi, layanan jasa, karya siswa, testimoni, kontak perusahaan, artikel, klien, dan daftar anggota / teams.

---- NOTE -----
Apabila gambar tidak terbaca:

1. masuk ke folder ' public > '
2. jika ada hapus folder 'storage'
3. di terminal jalankan perintah 'php artisan storage:link'
4. selesai.
